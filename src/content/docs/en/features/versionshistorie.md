---
title: Version History & Change Log
description: Every publication is traceable and reversible.
---

Paragrafy keeps two separate, complementary logs: a **version history** per legal text and a
global **change log** covering all admin actions.

## Version history

Every publication of a legal text automatically creates a new version — nothing is ever lost. In
the editor, a "Versions" tab per language shows the complete history:

- **Diff view** against the currently live version (green = added, red = removed)
- **Restore** an older version — non-destructive: restoring itself creates a new version, so the
  current version is never lost

## Change log (audit trail)

A dedicated "Log" tab in the admin area shows who changed what and when — not just legal text
publications, but also project settings, created/deleted document types, and changes to user
management. Every entry includes a timestamp, the acting person, and the affected resource. The
complete log can be exported as a CSV file — handy for internal records or questions from
colleagues.

:::tip[Managed Cloud vs. Self-Hosting]
Identical on both platforms, no extra setup needed — both logs run automatically in the
background.
:::
